# Notebooks

Place the project notebooks here:
- 01_finetuning.ipynb — training/fine-tuning the selected BERT-Tiny experiment.
- 02_model_evaluation.ipynb — standalone evaluation of one checkpoint on a fixed held-out set.
- 03_model_comparison.ipynb — paired comparison of BERT-Tiny, fast-langdetect, MIRA-IndicLID, and Sarvam.

Each notebook should state the data file expected, package versions, runtime/hardware, random seed, and whether results are measured or loaded from previously generated prediction sheets. Do not present cached timing values as fresh latency measurements.
