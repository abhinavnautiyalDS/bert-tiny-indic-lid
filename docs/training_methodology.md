# Training methodology

Fill this document from the final training notebook and run logs:
- Base checkpoint and model configuration.
- Tokenizer source and vocabulary size.
- Dataset source registry and license notes.
- Cleaning, normalization, deduplication, synthetic-data policy, and label mapping.
- Split strategy and leakage checks.
- Training hyperparameters, random seed, optimizer, scheduler, epochs, batch size, maximum sequence length, and compute.
- Best-checkpoint selection criterion.
- Artifact hashes and package versions.

Do not infer missing values from model names or report them as facts. Link to the exact notebook and run that produced the released checkpoint.
