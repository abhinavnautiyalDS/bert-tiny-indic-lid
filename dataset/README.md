# Dataset release

This folder is reserved for the exact dataset version used for the released checkpoint.

Before publishing, document:
- Original dataset names and source URLs.
- License/terms and attribution for every source.
- Raw, cleaned, deduplicated, and final row counts.
- Label definitions, annotation policy, and handling of unsupported/ambiguous text.
- Synthetic-data generation method and proportion, if applicable.
- Train/validation/test split method, random seed, grouping strategy, and duplicate audit.
- Whether test data overlaps with training templates or source corpora.

Do not upload source data unless its license permits redistribution. If redistribution is not permitted, publish a preparation script and source manifest instead. Never publish private call transcripts or personal information.
